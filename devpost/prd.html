SlipVector — Product Requirements

Detailed behavioral specification, 5 presets, sandboxed extraction, and solver architecture

The Core Journey

  1. Landing & Orientation: Interactive console with 10-Second Guided Demo button.
  2. Select Preset: 5 presets including 48px WCAG AAA Stress Case that defeats static strawmen.
  3. Dual Telemetry: Side-by-side display of static WCAG checks vs. kinetic Monte Carlo collision rates ($k/N$ + Wilson 95% CI).
  4. Visual Swarm: 60 FPS Canvas rendering trajectories, scatter markers, approach cone covariance ellipse, and Gaussian heatmap.
  5. Sensitivity Analysis: Real-time sweep across overshoot ratio $\sigma_\parallel/\sigma_\perp$ and tremor amplitude.
  6. Auto-Heal Solver: Repulsive layout solver computes certified safe coordinates and validates $0/N$ via re-simulation.
  7. Mitigation Trade-Offs: Quantitative comparison against Undo Toast, Overflow Menu, and Confirmation Modal.
  8. Export & Dogfood: Copy CSS/Tailwind patches, download JSON audit receipt, or audit SlipVector's live toolbar.

Functional Requirements Matrix

FR1: 5 Built-in Presets

SaaS Modal (28px), Mobile Commuter (2.5Hz sway), Clinical Keypad, Git PR Bar, and 48px WCAG AAA Stress Case where targets pass static checks but collide kinetically.

FR2: Sandboxed HTML Inspector

Extracts interactive elements via <iframe sandbox="allow-same-origin" srcdoc="..."> with semantic role classification and role overrides.

FR3: Self-Dogfooding Audit

1-click button to extract live dimensions of SlipVector's own toolbar controls and prove 0/500 collisions.

FR4: Parametric Motor Profiles

Steady Baseline, 4–8 Hz Essential Tremor, 2.5 Hz Transit Sway, Parkinsonian model approximation, and One-Handed Reach.

FR5: Visual Telemetry Canvas

Animated trajectories, covariance ellipses, shape-coded scatter markers, Gaussian heatmap, and prefers-reduced-motion support.

FR6: Constrained Auto-Heal Solver

Displaces destructive elements orthogonal to approach vector and expands targets; reports solved or honest infeasible bound.

FR7: Mitigation Matrix

Compares Spatial Separation vs. Undo Toast vs. 2-Step Overflow vs. Confirmation Dialog on collision risk and interaction time.

FR8: Sensitivity Sweep

Real-time mini-chart across overshoot ratio (1.0 to 2.5) and oscillation amplitude (0 to 20px) with Wilson 95% error bars.

FR9: Opt-In Perturbation Mode

Direct in-browser cursor perturbation test for hands-on ergonomic stress feeling with Esc key dismissal.

FR10: Measured Telemetry & Export

Reports live Web Worker execution time in ms; exports production CSS patches, Tailwind classes, and JSON audit receipts.
