SlipVector — Technical Architecture

Web Worker Monte Carlo engine, TypeScript biomechanics pipeline, and constrained solver

Biomechanical Pipeline Architecture

1. PRNG & Seeds

Deterministic mulberry32 generator and Box-Muller Gaussian sampling with bit-for-bit reproducibility across runs.

2. MacKenzie Shannon Fitts

$ID = \log_2(D/W + 1)$, calibrated $a=150$ms, $b=135$ms/bit, yielding throughput $TP \in [3.0, 6.5]$ bits/s matching empirical mouse literature.

3. Meyer Impulse Scatter

Approach vector rotation $\hat{\mathbf{u}}$ with $\sigma_\perp = k_{\text{aim}} \cdot D \cdot u$ and $\sigma_\parallel = \rho_{\text{overshoot}} \cdot \sigma_\perp$, strictly decoupling target width from cursor noise.

4. Continuous Tremor

Ornstein-Uhlenbeck stochastic drift plus sinusoidal oscillation $\mathbf{\eta}(t)$ integrated through transit and 90ms actuation dwell.

Mathematical Formulations

1. MacKenzie (1992) Shannon Formulation:
   ID = log2(D / W + 1)
   MT = a + b * ID
   TP = ID / MT

2. Approach Vector & Orthogonal Basis:
   u_hat = (x_target - x_anchor) / ||x_target - x_anchor||
   v_hat = (-u_y, u_x)

3. Meyer et al. (1988) Ballistic Endpoint Noise:
   sigma_perp     = k_aim * D * urgency
   sigma_parallel = rho_overshoot * sigma_perp

4. Wilson Score 95% Confidence Interval:
   p_hat = k / n
   Center = (p_hat + z^2 / (2n)) / (1 + z^2 / n)
   Margin = (z / (1 + z^2 / n)) * sqrt(p_hat * (1 - p_hat) / n + z^2 / (4n^2))
